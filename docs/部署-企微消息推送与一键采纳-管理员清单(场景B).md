# 江湖 × 企业微信 消息推送 + 一键采纳 — 管理员配置清单（场景 B 验证）

> 给企业微信**管理员**：在企微管理后台（<https://work.weixin.qq.com>）按下面步骤操作。
> 分**两个阶段**：第一阶段现在就能做（约 20 分钟）；第二阶段等开发侧通知再做（5 分钟，提前做会验证失败）。
> 与《部署-企微日历接入清单(管理员).md》用的是**同一个自建应用**——如果日历清单的 ①② 已做过，直接跳过对应步骤。

## 背景（一句话）

我们要验证：销售在**企业微信里直接收到**江湖的提醒卡片（如「钱大钧态度变更提案，影响 −12%」），**点卡片上的「采纳」按钮即生效**，不用打开系统。

---

## 第一阶段 · 现在就做

### ① 自建应用 + 3 个凭据　⭐必做（日历清单做过则跳过）

1. 企微后台 →「**应用管理**」→「**应用**」→「**自建**」→「**创建应用**」，应用名建议 `江湖助手`（若已建「江湖日历同步」，**直接复用它**，不要建第二个）。
2. 应用详情页记下 **AgentId**；点 Secret 的「查看/获取」（会推送到你的企业微信），复制出 **Secret**。
3. 「**我的企业**」→「**企业信息**」→ 最底部复制「**企业ID（CorpId）**」。

**【回收 ①】** CorpId、AgentId、Secret

### ② 可见范围加入测试成员　⭐必做

应用详情页 →「可见范围」：把参与验证的成员（至少你自己 + 1 名销售）加进去。
> ⚠️ 不在可见范围内的人收不到任何消息（报错 81013）。

**【回收 ②】** 测试成员的**账号（userid）**：通讯录 → 点开成员 → 「账号」一栏的值（形如 `ZhangSan`）。每人一个，发给开发侧。

### ③ 企业可信 IP　⭐必做（这次的新增关键步骤）

江湖服务器调用企微接口时，出口 IP 必须在应用的可信名单里，否则推送直接被拒（报错 60020）。

1. 先拿服务器出口 IP —— 在 **nova-jianghu 服务器**上执行（这步是服务器运维做，不是企微后台）：
   ```bash
   curl -s ifconfig.me
   ```
   把输出的 IP 记下来。
2. 企微后台 → 该应用详情页 →「**开发者接口**」→「**企业可信IP**」→「设置」→ 填入这个 IP。

**【回收 ③】** 已配置的出口 IP（发给开发侧留底）

### ④ 可信域名　⭐必做（日历清单做过则跳过）

1. 应用详情页 →「**网页授权及 JS-SDK**」→ 设置可信域名：`nova-jianghu.glodon.com`（不带 https）。
2. 按提示下载域名校验文件（`WW_verify_xxx.txt`），**把文件发给开发侧**放到服务器根目录，然后回来点「校验」。
> 域名主体（广联达）与企微主体一致，校验可直接过。

**【回收 ④】** `WW_verify_xxx.txt` 校验文件

---

## 第二阶段 · 等开发侧通知后再做（提前做会失败）

### ⑤ 接收消息 API（一键采纳的回调通道）

> ⚠️ 企微在**保存这一步时会立即向 URL 发验证请求**——必须等江湖的回调接口部署上线后再配，开发侧会专门通知你。

1. 先拿 URL：江湖 →「⚙️ → 📆 企微日历」→ 区块③「消息推送与一键采纳」→ 复制**回调 URL**（含你工作区专属路径，形如 `https://nova-jianghu.glodon.com/api/wecom/callback/<工作区ID>`）。
2. 应用详情页 →「**接收消息**」→「**设置 API 接收**」：
   - **URL**：粘贴上一步复制的
   - **Token**：点「随机获取」
   - **EncodingAESKey**：点「随机获取」
3. ⚠️ **先把 Token 和 EncodingAESKey 填回江湖设置页区块③并点「保存回调配置」，再回企微后台点保存**（顺序反了企微会验证失败）。
4. 若仍报「URL 验证失败」，联系开发侧排查后重试。

**【回收 ⑤】** Token、EncodingAESKey

## 附 · 开发侧（江湖）配套待办与验收路径

管理员无需操作，列出来是让你知道整个验证长什么样：

**开发侧待办**（第一阶段管理员操作的同时进行）：
1. 实现 `/api/wecom/callback` 回调端点：GET 验证（echostr 解密回显）+ POST 事件接收（WXBizMsgCrypt AES-CBC 解密）——这是第二阶段⑤的前置。
2. `WeComConfig` 扩 callbackToken / callbackAesKey（加密存）+ 设置页新增两输入框。
3. 消息推送：`message/send` 文本卡片（V1）→ 模板卡片 button_interaction（V2）；按钮事件 → 执行提案采纳/驳回 → 回调「更新模板卡片」把按钮刷成「已采纳 ✓」。
4. 放置域名校验文件、提供测试推送入口。

**三步验收（依次通过即场景 B 验证完成）**：
- **V1 推送通**（只需第一阶段①②③）：江湖向测试成员推一条文本卡片 → 手机企微收到。
- **V2 按钮通**（需第二阶段⑤）：推模板卡片 → 点「采纳」→ 服务器收到 template_card_event → 卡片自动刷新为「已采纳 ✓」。
- **V3 业务通**：用真实待审提案走一遍——企微点「采纳」→ 江湖收件箱该提案变已采纳 → 趋赢力重算生效。

> 排错速查：收不到消息 → 查可见范围（81013）/ 可信 IP（60020）/ userid 拼写；模板卡片发送报错 → 应用未配回调 URL（模板卡片要求⑤已完成，文本卡片不要求）。
