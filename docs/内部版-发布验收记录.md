## 2. RC 发布说明

- `CommandRun.idempotencyKey` 改由中央 runner 统一保存 SHA-256；兼容普通命令的存量 raw key 和 person-merge 的存量已哈希 key。
- PostgreSQL migration 在独占锁内失败关闭地迁移存量命令 key；发现异常 person-merge key 或唯一冲突即停止发布。
- App 新实体 ID 使用 `crypto.getRandomValues` 生成 128-bit opaque ID，兼容公司内网 HTTP；服务端停止截断 UUID。
- Person 增加跨库可移植的 `createdAt`，让“观察窗口内新建正式人物的重复合并率”可以直接计算。
- Vite/Vitest 构建测试依赖升级，完整依赖树与生产依赖树均执行 high/critical 门禁。
- CI 补齐 G64111、PostgreSQL schema drift、全包依赖审计和生产镜像构建。
- 增加三套脱敏旅程的自动化证据、受控运行指标提取、发布前回滚点和显式生产回滚脚本。
