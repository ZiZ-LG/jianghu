# 推演坞 · 第 6 刀「旁支退役」施工方案（风险/假设/弹药 砍容器，坞成真三层）

> 状态：**已施工完成（2026-07-02）**。信号条+汇总窗口删除、弹药/假设 UI 全退（存量留库实测：2 条 assumption + 4 条弹药在库不渲染）、风险降级坞头 `.dock-risk` 红条（⚠＋ inline 加雷回车落库 · ✕ 排雷云端同步 · severity 留库不展示）。AdvisorPanel 仅微调落点文案。门禁 80 测全绿；preview 实测加雷/排雷链路、三档高度红条常驻（collapsed 可见）、亮暗、860 窄屏无溢出。
> 原则：**简洁有效**——效用低、使用成本高的功能砍掉或精简，不强制要求分析模型绝对完备。方法论概念（风险/假设/弹药）不等于产品容器；产品只为「机器要算 / 多人要对齐 / 高频回看」的数据建结构化容器。
> 背景：第 5 刀已把汇总窗口瘦成两栏（风险假设 + 弹药），本刀追问后判定容器本身不该存在。

## 记账依据（判决表）

| 对象 | 效用 | 成本 | 判决 |
|---|---|---|---|
| 🎒 弹药 StrategyResource | 零计算消费；与行动 resources/props 双录；参谋行动牌 resources 为自由文本不引用池 | 独立 CRUD 维护 | **实体 UI 全退** |
| 假设 kind=assumption | 零计算消费；无验证闭环（不像证据有 E2 背离），录完即死；语义被策略卡 basis（隐含前提）+ alternatives（B 计划）双重覆盖 | 显式化维护前提 | **UI 全退** |
| ⚠ 风险 kind=risk | 高危雷常驻示警影响强攻/止损人工判断；参谋出牌第三类候选的落点 | 一行字，低 | **砍容器与 severity，降级坞头红条** |

**事实底（2026-07-02 核查）**：`aiContext.ts` / G64111 / PDE 均不消费风险与弹药（纯展示便签）；唯一活依赖 = 右栏参谋 `AdvCand` 的 `kind:'risk'` 候选（`server/src/strategy.ts` 参谋出牌，采纳落 `ADD_STRATEGY_RISK`）；对话链路（voiceExtract/ChatPanel）不提取风险/弹药，本刀不为其加提取类型。

## 目标态（坞真三层）

```
坞头：四动作徽章(唯一赢面) + 741 药丸 + 警示区（🔔 机器背离黄条 · ⚠ 人工雷红条）
四列：① 局势 → ② 策略 → ③ 倒排 → ④ 行动
坞底：💬 和地图对话（唯一坞底内容）
```

- 人工雷红条：与 `.dock-shift` 同族并列；行内 ＋ 添加、✕ 删除；**无 severity 分档、无管理窗口**——坞头空间即数量约束（没人置顶八条雷），比分档诚实。

## 动刀清单

1. **信号短条 + 汇总窗口整体退役**（`DeliberationDock.tsx`）：`sb2-signal` 条与 `sb2-summary` 展开区删除（渲染层）；`summaryOpen`/`showSummary` 状态清理；弹药 CRUD 调用（addResource/updateResource/deleteResource）删除。
2. **坞头人工雷红条**（新 `.dock-risk`，语义红 #dc2626）：渲染 `kind==='risk'` 的 StrategyRisk 为红条（collapsed 也可见，同背离行）；行内 ＋（最小 inline 输入）→ `ADD_STRATEGY_RISK`（`newStrategyRisk(accId, oppId, 'risk')`，severity 字段留库不展示）；✕ → `DELETE_STRATEGY_RISK`。
3. **假设 UI 全退**：无「＋假设」入口；存量 `kind==='assumption'` 不渲染、留库。
4. **弹药 UI 全退**：存量留库；`ADD/UPDATE/DELETE_STRATEGY_RESOURCE` Action、mutate 分支、store 逻辑**全部保留**（数据契约零改动，仅前端无入口）。
5. **参谋 risk 候选落点**：采纳仍走 `ADD_STRATEGY_RISK`，展示自动进坞头红条（AdvisorPanel 零改动或微调提示文案）。备选「risk 类并进行动牌 cautions、参谋只出两类」**本刀不做**，留观察。
6. **样式**：`.dock-risk` 新增；`.sb2-signal/.sb2-sig-*/.sb2-summary/.sb2-sum-*/.sb-risk/.sb-sev/.sb-res*` 系列保留不挂载（照退役惯例）。

## 数据处置

- 表、字段、Action 契约、mutate 全不动（铁律⑤零波及；跨库零风险）。
- 存量 assumption/弹药/低中危风险：留库不展示。当前线上无真实用户（nova-jianghu 待开放、Mac mini 团队验证期），**迁移负担 ≈ 零，正是砍的窗口期**。

## 验收

- 坞只剩真三层：坞头（徽章+药丸+双色警示区）/ 四列 / 对话；信号条、汇总窗口、弹药、假设不再出现。
- 红条链路：坞头 ＋ 加一条雷 → 常驻显示（三档高度均可见）→ ✕ 删除；参谋 risk 候选采纳 → 红条出现。
- 背离黄条与人工红条并存不打架（同时各造一条）。
- 门禁：`cd app && npx tsc --noEmit && npm run test`（80 测）+ preview（1360 三档 + ≤900 单列 + 亮暗）。
