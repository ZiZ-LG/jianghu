# 第一批个人 CRM：地图查证与行动接续

本记录覆盖 CORE-208、CORE-209、CORE-210、SAAS-213、SAAS-216 的本地工程验收。用户体验验收、候选精确 SHA 的远程检查、main 集成和发布分别记录，不互相替代。

## 体验路径

本地隔离预览：`http://127.0.0.1:5188/matters`，API 仅监听 `127.0.0.1:3188`。合成库位于 `/tmp/jianghu-batch1-preview-qodmwmer/preview.db`；没有生产数据、模型 Key、方法论包或外部 Agent。临时预览不是部署。

1. 注册私人账户，添加客户，记录只有名称的线索；业务目标和阶段可以留空。
2. 进入商机，添加已知人物，点人物或关系查看来源；同一联系人可加入另一商机，本次决策作用独立。
3. 记录转述/亲历/推断，人工引用依据并确定暂时的关注与缺口；不知道决策人时保留未知。
4. 打开行动草稿，修改对象、目的、时间与预期，确认保存后从“今日”继续；可从今日卡片返回原商机。
5. 暂停商机后在状态筛选中找回；手机切换列表继续阅读和操作。

## 已观察到的真实边界

| 场景 | 本地结果 |
|---|---|
| 私人注册与重登 | 无组织名注册成功，事务失败无孤儿租户；重复登录与刷新仍为当前私人范围 |
| 待判断线索 | 只填名称可保存；手动补阶段/目标、暂停、筛选找回保留同一 ID |
| 地图只读操作 | 选择人物、切地图/列表、打开行动草稿，浏览器观察到 0 次命令请求 |
| 行动确认 | 确认后恰好一次 Commitment POST，原商机和今日出现相同行动；目的/对象/时间/预期均保留 |
| 关系与来源 | 真表单创建关系及来源，实线点击可选；转述仍显示“待核实”，未成为已证实事实 |
| 同人不同商机 | 浏览器在第二商机复用同一 Person 并更改作用，第一商机作用保持不变 |
| 来源更新/撤回 | 通过隔离合成账户的真实命令更新、归档、恢复；刷新后旧作用和旧正文不在页面，草稿关闭并提示复核；恢复来源仍需重新引用新版本 |
| 待验证判断 | 保存后状态仍待验证，预期/反证条件可读；建立验证行动先打开草稿，保存绑定准确判断修订 |
| 手机路径 | 390×844 列表/详情实测 document 宽度 390，无横向溢出，选择仍指向原 Person |
| 浏览器错误 | 实测路径无 console error；修复了竖直关系的零宽点击区域，用透明面提供可点击范围 |
